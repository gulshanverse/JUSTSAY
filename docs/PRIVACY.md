# JUSTSAY Privacy Guidelines

## Strict Privacy Mandates
1. **No Sensitive PII Collection**: JUSTSAY strictly forbids collecting precise GPS location, device hardware serial numbers, contacts, advertising IDs, or IP logs for analytics.
2. **Coarse Hints Protocol**: Senders can voluntarily include safe, non-identifying contextual tags (e.g., "Sent late night 🌙" or "Sent via Web Client"). Hardcoded or invasive fake location strings ("iPhone 15 in New York") are strictly removed.
3. **Recipient Decoupling**: Recipients never receive network sockets, IP addresses, or account credentials of message submitters.
4. **Data Retention Policy**: Flagged or rejected messages are soft-deleted or permanently purged during maintenance cycles according to user request and compliance mandates.
